Welcome to the DPV-Nav toolkit.

Nominally, this is a simple inertial navigation system designed to be installed on DPVs (aka "scooters").  

First iteration is basic tilt-compensated heading + flowmeter-based distance calcs + a simple small display that reports bearing and distance to a home point.  Additionally, basic data-logging should be incorporated.
Future work could include bearing and range to a preset waypoint, or integration with bluetooth to calibrate on-site, or any variety of other things.
But at first: just the basics.
