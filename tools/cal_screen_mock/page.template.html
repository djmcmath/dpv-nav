Calibration screens in one frame

Each screen below is drawn pixel for pixel at the panel's 320 × 240, using the firmware's own 5×7 font and RGB565 colors, so text sizes look here as they will on the unit. The numbering presents heading calibration as three steps: 1 Baseline, 1a Fill gaps when the baseline result asks for it, 2 Mounted and 3 Heading.

Screen size
The panel is 2.0 in across the diagonal. Most screens draw this a little small.

The frame

Every calibration screen has the same four bands. Only the work area changes from step to step.

  1. Headery 0–23

    The step strip (1, 1a, 2, 3), the step name, and a counter. The counter always counts toward whatever ends the step: samples to 2160 on Baseline, target cells on Fill gaps, cells to 36 on Mounted, marks to 12 on Heading. On the closing screens it names the phase instead.

  2. Work areay 24–183

    The step's own widgets. This is the only band that changes from step to step.

  3. Statusy 186–209

    One line saying what to do now. Red means you're blocked, yellow means adjust, green means good. On closing screens it says what comes next.

  4. Keysy 212–239

    The left label is BTN1 and the right label is BTN2. Each one says what the button does right now. Dim text means not yet; an empty outline means that button does nothing on this screen.

BTN2 keeps going. Holding BTN1 throws the work away. A short BTN1 press only flashes "Hold BTN1 to quit" in the status line, so a diver can learn the hold without reading the manual.

1Baseline

Baseline starts on the bars and switches to the grid when the in-session fit locks. It ends when you press FINISH, or by itself when the sample buffer fills at 2160 (60 cells × 18 × 2). A full grid does not end it.

1aFill gaps optional

Only needed when the baseline result lists gaps. The counter is target cells done. The step ends by itself when every target is done, or when you press FINISH.

2Mounted

Mounted ends by itself when all 36 cells are filled, or when you press FINISH, which sends whatever you have. The server fits the level row, so it refuses a run with too few level cells (fewer than 30 still, level samples, or a gap wider than 90° around the circle), and the result screen says why. Today BTN1 here opens the menu where you can't see it. In the frame, every calibration screen owns both buttons.

3Heading

The target is what you steer to, using an external compass. The unit's own reading sits below it, smaller and gray, labeled INDICATED HDG so the two numbers don't read as a pair to make match. You can still see how far off the unit is. MARK turns green only when the level gate reports ready.

Every ending

The ending is the same for all four steps. The header keeps the step's name, so you never land on an anonymous CLOUD CAL screen. On results, the color of the number is the recommendation; after you accept, the Installed screen says what comes next.

Decided

  1. The steps are numbered 1, 1a (optional), 2 and 3. The 1a token shows on every screen.
  2. BTN2 keeps going. Holding BTN1 for 2 s throws the work away (QUIT, REJECT), and the left key fills while you hold.
  3. Results show the number in the grade's color plus a one-word grade: GOOD, OK or POOR.
  4. Mounted gets FINISH at any time and ends by itself at 36 cells.
  5. Grid guidance stays broad ("Fill red & yellow cells"), because per-cell hints would flicker as the unit rolls.
  6. On Heading, the target is the main number. The unit's indicated heading is secondary and labeled as such.
  7. Grid rows are 24 px on Baseline and Fill gaps, 20 px on Mounted.
  8. Accepting a baseline on the unit downloads its gap-fill map straight away. If that fails, the stale map is deleted.
  9. The Cal menu reads Baseline (1), Fill gaps (1a), Mounted (2), Heading (3), then Speed cal.
